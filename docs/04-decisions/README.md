# Implementation Decisions (ADRs)

> **Purpose:** Records non-trivial implementation choices made during development that are not already covered by the architecture baseline.
>
> The first ADR will be created during Step 2 or later, when a choice comes up that warrants documenting.

## Convention

Each ADR is a separate file: `ADR-NNN-title.md`

```markdown
# ADR-NNN: [Title]

**Date:** YYYY-MM-DD
**Status:** Accepted | Superseded by ADR-XXX
**Context:** [1-2 sentences: why this decision came up]
**Decision:** [What we chose]
**Consequences:** [What this means for the codebase]
```
