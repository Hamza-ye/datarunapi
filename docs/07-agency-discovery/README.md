# Agency Discovery Starter Packet

> Purpose: Give planning agents just enough context to reason about the full product direction without getting trapped in implementation details.

This packet is designed for multi-agent product discovery workflows where agents should focus on:
- what the product must achieve,
- why it matters,
- what boundaries must not be violated,
- and which scenario envelope defines early planning scope.
